# Code of Conduct

This project is small. The Code of Conduct can be too.

## What's expected

Be kind. Assume the other person is acting in good faith. If you disagree with someone, disagree with what they said, not who they are. If you're frustrated, take a walk before you reply.

These apply to issues, pull requests, discussions, and any other space connected to this project.

## What's not okay

- Personal attacks, insults, or harassment of any kind
- Sexualized language or imagery
- Sharing someone else's private information without permission
- Sustained disruption of conversations
- Anything that would make a reasonable person not want to participate

## If something goes wrong

If you experience or witness behavior that violates this code, email noel@aloy.dev. Reports are handled privately. The maintainer will respond within a few days.

Consequences for breaking this code can include warnings, having content removed, or being blocked from the project. The maintainer decides what's appropriate based on the situation.

## Scope

This code applies anywhere this project is being represented or discussed — GitHub issues and PRs, related chat or social posts, in-person events if any happen.

---

This Code of Conduct is loosely adapted from a number of small-project codes that prioritize plain language over legalese. If you have suggestions for improving it, open an issue.
